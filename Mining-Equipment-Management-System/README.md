# Mining Equipment Management System (MEMS)

## Project Overview

The Mining Equipment Management System (MEMS) is a proposed backend system designed to help mining companies organize and monitor equipment records, assignments, maintenance activities, and inspection results.

The system aims to provide a centralized database for managing equipment information and improving record accessibility, maintenance tracking, and accountability.

## Technologies

- **Backend Framework:** NestJS
- **Runtime Environment:** Node.js
- **Programming Language:** TypeScript
- **Database:** PostgreSQL
- **API Architecture:** RESTful API
- **Authentication:** JSON Web Token (JWT)
- **Authorization:** Role-Based Access Control (RBAC)
- **API Testing:** Postman
- **Version Control:** Git and GitHub
- **Planned Hosting:** Local Server

## Main Features

1. Equipment Inventory Management
2. Equipment Category Management
3. Mining Site Management
4. Equipment Assignment Tracking
5. Maintenance Records and Scheduling
6. Equipment Inspection Records
7. User Authentication and Role Management
8. Activity Logs and Basic Reports

## Database Design

The proposed database consists of nine tables:

1. users
2. equipment_categories
3. mining_sites
4. equipment
5. equipment_assignments
6. maintenance_records
7. maintenance_schedules
8. inspection_records
9. activity_logs

The database design targets Third Normal Form (3NF) to reduce data redundancy and maintain data integrity.

## Project Status

**Midterm Phase – Backend Design and Documentation**

The current phase focuses on planning the system architecture, database schema, RESTful API endpoints, authentication, authorization, security, testing, and deployment.

Backend implementation and API testing will be completed during the final project phase.
